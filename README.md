# Personal Portfolio

A modern, responsive portfolio website built with Next.js to showcase my experience, projects, technical skills, and achievements.

🌐 Live Website: https://nagbhushan.me

---

## Features

- Responsive design for desktop, tablet, and mobile
- Project showcase
- Experience timeline
- Skills section
- Contact links
- SEO optimized
- Fast loading and accessible UI

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

---

## Getting Started

Clone the repository

```bash
git clone https://github.com/<username>/portfolio.git
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Build

```bash
npm run build
npm start
```

---

## Deployment

The website is automatically deployed using Vercel.

Every push to the `main` branch triggers a new production deployment.
